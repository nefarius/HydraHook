# Security

HydraHook is a library that hooks Direct3D and Core Audio inside a process you load it into. Do not inject it into processes you do not own, and do not use it to bypass anti-cheat or other integrity checks.

## Reporting a vulnerability

If you believe you have found a security issue in this repository, open a private vulnerability report on GitHub (Security tab) or email the maintainer through the contact listed on their GitHub profile. Please include a description, the affected version or commit, and a minimal way to reproduce the problem.

Do not file a public issue for an unfixed vulnerability.

There is no bug bounty.
